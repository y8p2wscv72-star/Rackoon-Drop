# RACKOON — Telegram Mini App

Экраны: лобби, Crash (ракета), PvP-арена, Upgrade, Cases, Mines, инвентарь, задания, лидеры.
Сайт живёт на GitHub Pages (корень этого репозитория — собранная версия).

## Бесплатный кейс
Один — «Ежедневный», раз в сутки: 0.1 TON (99%) или 1 TON (1%), сразу на баланс.

## Ракета и PvP — реальные игроки
Раунды ведёт сервер из репозитория **rackoon-server** (WebSocket). Ботов нет: все видят ставки,
кэшауты, победителей и реакции друг друга, онлайн — настоящий.
Адрес сервера задаётся в `index.html`: `window.RK_SERVER = 'https://...'`.
Пока он не задан, ракета и PvP показывают «Нет связи».

Баланс игрока по-прежнему хранится у него на устройстве (демо). Для реальных денег
баланс и кейсы нужно перенести на сервер.

## Подключить к боту
В @BotFather: создать бота (/newbot), затем в настройках бота указать ссылку на сайт для Mini App / кнопки меню.

## Пересобрать после правок
Экраны лежат в `src/screens/*.dc.html` (разметка + логика), движок и сетевой модуль — `src/main.jsx`.
```
npm install react react-dom esbuild
./build.sh
```
Картинки берутся из папки `assets/` в корне репозитория (для сборки положи её в `public/assets`).
Затем содержимое `dist/` копируется в корень репозитория.
